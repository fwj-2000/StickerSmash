# 2026-10-19

## 修复 StickerSmash 报错：Class extends value undefined is not a constructor or null

**根因**：`expo-media-library@57` 的新 API（`MediaLibraryNext`）**没有 web 实现**。其 `src/index.ts` 顶层有
`export class Query extends ExpoMediaLibraryNext.Query {}`，而 `ExpoMediaLibraryNext.ts` 只有 `requireNativeModule`
调用、没有 `.web.ts`。web 静态渲染（`app.json` 里 `web.output = "static"`）时 `requireNativeModule.web.ts`
在 SSR 分支返回 `{}`，于是 `ExpoMediaLibraryNext.Query` 为 `undefined`，类继承 undefined 直接抛错。
浏览器端运行时则会抛 `Cannot find native module`，本质同一问题。

**关键认知**：`Platform.OS !== "web"` 的运行时判断救不了这个问题——错误发生在**模块加载期**，
import 语句本身就会执行类定义。必须做**文件级隔离**，用 Metro 的平台后缀解析。

**修复**：
- 新增 `src/lib/save-image.ts`（native：captureRef + `Asset.create()` + `requestPermissionsAsync(true)`）
- 新增 `src/lib/save-image.web.ts`（web：dom-to-image + `<a download>`）
- `src/app/(tabs)/index.tsx` 只 import `@/lib/save-image`，Metro 自动按平台选文件
- `app.json` 补 `expo-media-library` 插件（photosPermission / savePhotosPermission），否则原生构建缺
  NSPhotoLibraryUsageDescription / NSPhotoLibraryAddUsageDescription

**验证**：`npx expo export --platform web` 静态渲染 6 条路由全部通过；web bundle 中
`ExpoMediaLibraryNext` 出现次数为 0；`npx expo export --platform android` 打包正常；`tsc --noEmit` 无报错。

**项目环境**：Expo SDK 57.0.22 / RN 0.86.3 / React 19.2.3 / expo-router，`reactCompiler: true`。
